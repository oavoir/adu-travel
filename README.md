# ✈️ 여행플래너

**여행사 직원처럼 상담해서 일정을 짜주는 클로드 플러그인.**

"부모님 모시고 오사카 3박 4일" 한 줄이면 됩니다. 누구랑 가는지·뭘 하고 싶은지 물어가며 그 사람에게 맞는 일정을 만들고, 폰으로 보는 웹페이지 하나로 내줍니다.

부모님 모시고 가는 오사카와 친구들끼리 가는 오사카는 다른 일정이 나옵니다. 하루에 몇 군데를 도는지, 몇 시에 시작하는지, 어떤 식당을 고르는지가 전부 달라집니다.

---

## 설치

Claude Code에서 두 줄이면 됩니다.

```bash
/plugin marketplace add oavoir/adu-travel
```

```bash
/plugin install adu-travel
```

폴더째 넣고 싶으면 `skills/travel-planner` 를 `.claude/skills/` 에 복사해도 똑같이 동작합니다. 폴더명은 **ASCII로** 두세요 — 한글로 두면 호출 이름이 깨집니다.

### 클로드 앱에서 쓰려면

**Customize → Skills → `+` → `+ Create skill` → `Upload a skill`** 순서로 zip을 올립니다 (무료 플랜 포함 전 요금제 지원).

올릴 zip은 [`dist/travel-planner.zip`](dist/travel-planner.zip) 입니다.

다만 앱은 코드 실행 환경에 네트워크가 막혀 있어서 **유튜브 수집과 네이버 검색이 안 됩니다.** 인스타 캡션과 현지 맛집 플랫폼, 검산과 결과물은 그대로 됩니다. **국내 여행은 유튜브가 1차 경로라 앱에서는 특히 약합니다** — 해외 여행 위주로 쓰시는 걸 권합니다.

## 쓰는 법

**이렇게 말하고 시작하세요.**

```
adu-travel 플러그인 써서 여행 계획 짜줘.
부모님 모시고 오사카 3박 4일, 대중교통으로 다닐 거야.
```

앞에 **"adu-travel 플러그인 써서"** 를 붙이는 게 요령입니다. 여행 얘기만 해도 알아서 작동하지만, 명시해두면 확실합니다.

그다음은 이렇게 흘러갑니다.

1. **클로드가 되묻습니다** — 날짜, 몇 명인지, 어르신·아이가 있는지, 렌터카인지 대중교통인지, 이미 잡아둔 숙소나 항공편이 있는지. 이 답에 따라 일정이 완전히 달라지기 때문에 조사 전에 먼저 묻습니다
2. **직접 찾아옵니다** — 그 나라 사람들이 실제로 쓰는 맛집 사이트를 열어서 영업시간·정기휴무·전화번호·결제수단까지 확인합니다
3. **후보를 내밀고 고르게 합니다** — "저녁 후보 여덟 곳 찾았는데 세 밤이니 세 개만 고르세요"
4. **시간이 맞는지 검산하고** 웹페이지 링크 하나로 내줍니다
5. **"여기 빼줘", "점심은 라멘으로"** — 대화로 계속 고치면 같은 링크가 업데이트됩니다

첫 실행에서 폴더 만들기나 파일 읽기 **허용을 묻는 창이 뜰 수 있습니다.** 작업 폴더를 만들고 상담 기록을 저장하려는 것이라 허용하시면 됩니다.

## 결과물

탭 5개짜리 웹페이지가 나옵니다.

| 탭          | 내용                                                                        |
| :---------- | :-------------------------------------------------------------------------- |
| 📅 **일정** | 날짜별 시간표 · 주소(복사용)와 지도 링크 · 전화번호 · 예산 요약             |
| 🧳 **준비** | 출발 전 체크리스트 (실제 날짜로) — 여권·비자·사전등록·예약 오픈일 · 챙길 것 |
| 🍽️ **식당** | 지역별 맛집 (가격·전화·예약 필요 여부·현금 전용·정기휴무) · 끼니 배정       |
| 🛍️ **쇼핑** | 갈 곳 · 살 품목 (현지어 표기 포함)                                          |
| 🗣️ **회화** | 상황별 현지어 + 한글 발음 · 예약 전화 스크립트 · 긴급 정보                  |

체크하면 폰에 저장되고 **글자 크기 버튼**이 있어 어르신도 보기 편합니다. 한 번 열어두면 비행기 모드에서도 그대로 보입니다.

## 알아두면 좋은 것

**예약과 결제는 하지 않습니다.** 전화 스크립트와 링크까지 준비해드립니다.

**국내 여행은 해외보다 약합니다.** 네이버 통합검색과 블로그는 읽지만 지도와 업체 상세는 못 읽습니다. 경로는 네이버지도로 직접 확인하시는 걸 전제로 짭니다.

**검산은 시간이 맞는지 보는 것이지 정보가 맞는지 보는 게 아닙니다.** 영업시간을 잘못 읽었다면 그 값으로 계산해서 통과시킵니다. 그래서 모든 항목에 출처 링크를 남깁니다 — 중요한 곳은 한 번 확인해 보세요.

**모르는 건 모른다고 합니다.** 못 읽은 소스가 있으면 결과에 그대로 밝힙니다.

## 필요한 것

외부 MCP 서버는 필요 없습니다. 유튜브 수집에만 `yt-dlp`가 필요한데, **해외 여행은 없어도 돌아가고 국내 여행은 사실상 필수**입니다.

```bash
brew install yt-dlp
```

없으면 클로드가 먼저 알려주고, 설치를 기다리지 않고 다른 경로로 진행합니다.
