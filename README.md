# ✈️ 여행플래너 — 여행사 직원처럼 상담해서 일정을 짜줍니다

> 비행기표나 "도쿄 4박 5일" 한 줄만 말하면, 클로드가 **누구랑 가는지, 뭘 하고 싶은지, 어떤 페이스가 좋은지 물어가며** 그 사람에게 맞는 일정을 짜줍니다. 정해진 답을 뱉는 게 아니라 대화하면서 만들어갑니다.

**부모님 모시고 가는 도쿄와 친구들끼리 가는 도쿄는 완전히 다른 일정이 나옵니다.** 하루에 몇 군데를 도는지, 몇 시에 시작하는지, 어떤 식당을 고르는지, 숙소를 어디에 잡는지가 전부 달라집니다.

---

## 이런 분께

- 여행 갈 때마다 인스타에 맛집 릴스 수십 개 저장해놓고 **정작 여행 가서 못 찾는** 분
- 검색해도 죄다 광고 블로그라 **어디가 진짜인지** 모르겠는 분
- 비행기표는 끊었는데 **숙소를 어느 동네에 잡아야 할지** 감이 안 오는 분
- 일정표·맛집리스트·쇼핑리스트·회화·예산을 **한 페이지로** 들고 다니고 싶은 분

## 두 가지 방식으로 쓸 수 있습니다

**① 링크가 있으면** — 저장해둔 릴스·캐러셀·유튜브·블로그 링크를 한 번에 여러 개 붙여넣으세요. 전부 열어서 가게 이름·주소·가격을 뽑고, **링크별로 뭐가 나왔는지 표로 먼저 보여드린 다음** 일정에 녹입니다.

링크에서 나온 곳은 **이미 가고 싶다고 정하신 곳**이라 다른 후보보다 우선 배치합니다. 다만 검증은 그대로 합니다 — 릴스가 2년 전 것이면 폐업했을 수 있으니 게시일을 보고 현재 영업 여부부터 확인해요. 여행지에서 먼 링크는 말없이 빼지 않고 **근처 대체 스팟을 제안하거나 "다음 여행용"으로 저장할지** 여쭤봅니다. 못 뽑은 링크가 있으면 그것도 숨기지 않고 알려드립니다.

**② 링크가 없어도** — "도쿄 4박 5일, 부모님 모시고" 한 줄이면 됩니다. 클로드가 알아서 찾습니다.

대부분은 섞어서 씁니다. 링크 몇 개 주고 "나머지는 알아서 채워줘"가 제일 편합니다.

## 쓰는 법

1. 클로드에게 **여행 조건**을 말합니다 — 날짜, 인원(어르신·아이·식이제한 포함), 숙소, 렌터카/대중교통, 항공편
2. 링크가 있으면 **복사해서 붙여넣습니다**
3. 클로드가 그 나라 맛집 소스를 뒤지고 → 영업시간·휴무·전화번호를 확인하고 → 동선에 맞춰 일정을 짜서 → **웹페이지 링크 하나**로 만들어줍니다
4. "여기 빼줘", "점심은 라멘으로", "이 릴스도 봐봐" — 대화로 계속 수정하면 **같은 링크**가 업데이트됩니다 (체크한 것도 그대로 유지)
5. 완성되면 **공유 설정을 켜고** 동행자에게 링크를 보냅니다

## 이 스킬이 특별한 이유

### 1. 유튜브·인스타를 실제로 뒤져서 찾아옵니다

아는 걸로 대충 채우지 않습니다. 그 자리에서 직접 나가서 긁어옵니다.

- **유튜브 챕터·설명란** — 여행지 음식 가이드 영상을 찾아서 **챕터와 설명란에서 가게 이름과 공식 사이트를 뽑습니다.** 자막을 전사해서 "여긴 줄이 길지만 30분이면 빠진다" 같은 실제 평가까지 읽고요
- **유튜브 댓글** — 좋아요 상위 댓글에서 **"저 가격이면 안 간다", "작년에 주인 바뀌었다"** 같은 반대 신호를 찾습니다. 영상은 홍보여도 댓글에는 반박이 달립니다
- **인스타** — 링크를 안 주셔도 찾습니다. 한국인 여행 계정이 캡션에 맛집 리스트를 통째로 적어두는 문화라 **한국어 검색으로 수확이 가장 큽니다.** 저장해둔 릴스를 던지시면 슬라이드까지 넘겨가며 읽고요
- **국내 여행이면 네이버 통합검색** — 상호·별점·리뷰수·지금 영업 중인지까지 봅니다 (광고 항목은 걸러냅니다)

그리고 여기서 나온 후보를 **그대로 쓰지 않고** 아래 플랫폼에서 영업시간·휴무·전화번호를 확정합니다. 유튜브 자막은 가게 이름을 뭉개고("wagyu"를 "wagu"로), 영상은 2년 전 것일 수 있으니까요.

**여러 소스에 동시에 나온 곳**을 우선합니다. 유튜브 챕터에도 있고 댓글에 반박이 없고 현지 플랫폼 점수도 높으면 거의 확실합니다.

> 📅 **레딧과 X는 2026-08-13부로 못 읽습니다.** 일주일 전만 해도 열리던 경로가 전부 막혔습니다(레딧 8개 경로 게이트, X는 결제 요구). 반대 신호는 위의 유튜브 댓글과 "tourist trap" 류 검색으로 대신합니다. **못 읽은 소스는 결과에 그대로 밝힙니다.**

### 2. 나라마다 다른 "진짜 맛집 사이트"를 찾아갑니다

우리가 네이버 지도를 쓰듯 나라마다 현지인이 쓰는 곳이 따로 있습니다. 일본은 타베로그, 홍콩은 오픈라이스, 태국은 웡나이, 베트남은 푸디, 싱가포르는 버플. 클로드가 그 나라 소스를 직접 읽고 후보를 뽑습니다.

**점수 읽는 법도 나라마다 다릅니다.** 타베로그 3.5점은 낮아 보이지만 **상위 3%**이고 4.0점은 상위 0.07%입니다. 베트남 푸디는 아예 10점 만점이라 7점이면 평범한 축입니다. 이걸 모르고 "4점 넘는 곳만" 고르면 일본 맛집을 전부 걸러내게 됩니다.

### 3. 비행기표 한 장에서 숙소 동네를 역산합니다

편명만 알려주면 **도착 터미널**을 확인하고, 입국심사와 짐 찾는 시간, 공항에서 시내까지 이동시간을 더해서 **첫날 밤에 몇 시에 시내에 도착하는지**를 계산합니다. 너무 늦으면 첫날만 공항 근처에 잡는 안을 제안합니다.

먼저 **동네를 2~3곳**으로 좁힙니다. 갈 곳들의 무게중심, 환승 횟수, 캐리어 끌고 갈 거리를 근거로요.

그다음 **그 동네의 실제 호텔 후보를 가져와서 3~5곳 비교표로** 보여드립니다. 이름·평점·1박 가격에 더해 **리조트피까지** 나란히 놓고, 각각 왜 골랐는지와 트레이드오프("제일 싸지만 해변에서 멉니다")를 붙입니다. **고르는 건 사람이 합니다** — 숙소는 취향과 예산이 갈리는 영역이니까요.

리조트피는 특히 중요합니다. 예약 사이트 가격에 안 들어 있는데 와이키키 기준으로 리조트피 $45~54에 주차 $45~93이 매일 붙어서, **1박에 $110가 통째로 빠져 보일 수** 있거든요. 그래서 후보를 추린 뒤 호텔 공식 사이트에서 따로 확인해 표에 넣습니다.

### 4. 일정이 실제로 굴러가게 짭니다

- **하루 3곳 기본, 최대 4곳.** 욕심내면 무조건 무너집니다
- **인기 관광지는 개장 직후**, 도착 시간까지 역산해서 출발 시간을 지정
- **휴관일을 실제로 확인합니다.** 루브르는 화요일, 우피치는 월요일, 바티칸은 일요일 — 월요일이라고 다 같지 않습니다
- **밥 못 먹는 시간대를 압니다.** 일본 식당은 15~17시에 브레이크타임이 있고, 프랑스는 14시 반부터 18시까지 주방이 닫힙니다. 파리는 식당의 40%가 일요일이나 월요일에 쉽니다
- **이동시간을 실제로 계산합니다.** 지도 위 직선거리가 아니라 대중교통 경로로요
- 어르신 동행이면 도보량 반영, 비 오는 날 실내 대체안, 주차비·톨비·면허 서류까지 선제 안내

### 5. 출발 전에 놓치면 못 가는 것부터 챙깁니다

일정이 아무리 좋아도 여권이 5개월 남았으면 소용없습니다.

- **여권 유효기간** — 나라마다 요건이 다릅니다. 목적지 기준을 그 자리에서 확인해서 알려드립니다 (일본처럼 6개월 요건이 없는 나라도 있습니다)
- **비자·사전등록** — 필요 여부와 신청 링크, 소요 시간(ESTA는 최대 72시간)
- **현지 공휴일** — 골든위크·국경절·부활절에 가면 예약이 안 되고 가격이 뜁니다. 겹치면 먼저 알려드립니다
- **예약 오픈일** — 안네 프랑크 하우스는 매주 화요일 10시에 정확히 6주 뒤 날짜만 열리고, 놓치면 그냥 못 들어갑니다. 이런 건 일정을 짜기 전에 확인합니다

이걸 전부 **실제 날짜로 된 체크리스트**("D-30" 아니라 "3월 12일까지")로 만들어서 결과물의 준비 탭에 넣어드립니다.

### 6. 일정이 시간상 진짜 되는지 검산합니다

대부분의 AI 일정표가 무너지는 지점입니다. 장소는 잘 골랐는데 이동시간을 안 더했거나 폐관 시각을 안 본 경우죠.

완성한 일정을 **시작 시각부터 분 단위로 돌려봅니다.** 개장 전에 도착하는지, 폐관 1시간 전까지 들어가는지, 저녁 먹고 막차를 탈 수 있는지, 하루 도보량이 몇 km인지. 안 맞으면 고치고 **고쳤다고 말씀드립니다.**

> 3일차 — 09:00 출발 → 숙소 복귀 19:40 · 이동 1시간 50분 · 도보 약 3.2km · 3곳
> ⚠️ 저녁 식당 라스트오더가 20:30이라 앞 일정을 20분 당겼어요.

### 7. 예약은 못 하지만, 3분 만에 끝낼 재료를 드립니다

전화 예약은 문장이 정형화돼 있어서 스크립트가 실제로 통합니다. **날짜·시간·인원·이름을 채운 완성 문장**과 한글 발음, 상대가 할 말("만석입니다", "성함이?")까지 준비해드립니다. 이메일·왓츠앱 예약이 표준인 나라는 현지어 초안으로요.

**알레르기가 있으면 현지어 카드**를 만들어드립니다. 일본은 거의 모든 국물에 가쓰오부시가 들어가고 동남아는 피시소스가 기본이라, 숨은 재료까지 적어야 안전합니다. 다만 중증 알레르기는 의료 번역이 검증된 전문 카드를 함께 쓰시라고 안내합니다.

### 8. 모르는 건 모른다고 합니다

읽을 수 없는 사이트가 있습니다. 예를 들어 한국의 네이버는 클로드가 접근할 수 없습니다. 그런 경우 아는 척하지 않고 **"이 부분은 커버리지가 얕다"고 밝히고** 다른 경로로 찾습니다. 영업시간이나 가격을 추측으로 채우지 않습니다.

### 9. 스크린샷 달라고 하지 않습니다

릴스가 안 열리면 보통 "캡처해서 주세요"라고 하죠. 이 스킬은 브라우저로 직접 들어가 로그인 팝업을 닫고 캐러셀 슬라이드를 한 장씩 넘기며 읽습니다. 그래도 안 되면 웹에서 교차검증합니다.

## 솔직한 한계 — 쓰기 전에 아셔야 하는 것

좋게만 써두면 기대와 다를 때 손해는 쓰는 분이 봅니다. 그래서 지금 약한 지점을 그대로 적습니다.

**국내 여행은 해외보다 약합니다.** 네이버 **통합검색**은 읽어서 상호·별점·리뷰수·영업 여부까지 봅니다(2026-08-13 확인). 다만 **개별 업체 상세 페이지와 지도는 여전히 못 읽고**, 다이닝코드·카카오맵·대한민국구석구석·비짓부산도 자바스크립트로만 뜨는 페이지라 못 읽습니다. 그래서 **유튜브로 발굴하고 통합검색으로 교차 확인한 뒤 개별 가게 공식 소스로 확정**하는 방식으로 짭니다. 해외처럼 "랭킹 페이지에서 영업시간까지 한 번에"는 안 됩니다. 경로 확인은 네이버지도로 직접 해보시는 걸 전제로 짭니다.

**검산은 시간이 맞는지 보는 것이지 정보가 맞는지 보는 게 아닙니다.** 영업시간을 잘못 읽었다면 그 잘못된 시간으로 계산해서 "통과"라고 답합니다. 그래서 모든 항목에 **출처 링크**를 남깁니다 — 중요한 곳은 그 링크로 한 번 확인해 보세요.

**직접 확인해본 지역과 조사만 한 지역이 섞여 있습니다.** 일본·한국·미국은 실제로 열어보며 만들었고, 유럽·남미·중동은 조사 기반이라 첫 작업 때 소스부터 다시 확인합니다. 그 지역이면 "제가 직접 확인해본 적 없는 지역"이라고 먼저 말씀드립니다.

**예약과 결제는 하지 않습니다.** 전화 스크립트와 링크까지만 준비합니다.

## 실사용 예시

> **오사카 3박 4일 (가족 여행, 렌터카)**
> 인스타 링크 40여 개 → 식당 33곳(지역별)·쇼핑 40여 항목·액티비티 정리.
> 유니클로 한정 이벤트 마감일을 잡아내 가능한 날에 배치하고, 어촌 마을 당일치기 동선(주차장 주소 포함), 주말 명소 새벽 공략, 불꽃축제 비교, 예산 합산까지 — 웹페이지 하나로.

## 설치

Claude Code에서 플러그인으로 설치합니다.

```bash

```

```bash

```

설치하면 여행 얘기를 할 때 자동으로 작동합니다. 따로 명령어를 외울 필요는 없습니다.

**폴더째 넣고 싶으면** `skills/travel-planner` 폴더를 `.claude/skills/`에 복사해도 똑같이 동작합니다.

### 터미널을 안 쓰신다면 (클로드 앱)

클로드 앱에서도 쓸 수 있습니다. **Customize > Skills** → `+` → `+ Create skill` → `Upload a skill` 순서로 zip을 올리면 됩니다 (무료 플랜 포함 전 요금제 지원).

바로 올리실 zip은 여기 있습니다 — [`dist/travel-planner.zip`](dist/travel-planner.zip). 직접 만드시려면 `skills/travel-planner` 폴더가 **zip의 최상위**가 되도록 압축하세요.

**다만 앱에서는 절반이 막힙니다.** 앱의 코드 실행 환경은 보안상 네트워크가 완전히 차단돼 있어서(`Internet access: Completely disabled`), 유튜브 수집(`yt-dlp`)과 네이버 통합검색이 **아예 나가지 못합니다.**

|                                | 클로드 코드 |    클로드 앱     |
| :----------------------------- | :---------: | :--------------: |
| 인스타 캡션 · 현지 맛집 플랫폼 |     ✅      |        ✅        |
| 유튜브 수집·댓글 · 네이버 검색 |     ✅      |        ❌        |
| 작업 파일 누적                 |     ✅      | ⚠️ 대화 안에서만 |
| 검산 · 일정 조립 · 결과물      |     ✅      |        ✅        |

**국내 여행은 유튜브가 1차 경로**라 앱에서는 특히 약합니다. 해외 여행 위주로 쓰시는 걸 권합니다. 링크도 **한 번에 10개 이하**로 나눠 주세요 — 앱에서는 작업 큐 파일을 못 써서 긴 목록이 중간에 흐려집니다.

### 필요한 것

**외부 MCP 서버는 필요 없습니다.** 웹 조회와 기본 도구만으로 동작합니다.

유튜브 수집에는 `yt-dlp`가 필요합니다. **해외 여행은 없어도 나머지 경로로 돌아가지만, 국내 여행은 사실상 필수입니다** — 네이버 계열이 전부 막혀 있어서 유튜브가 1차 발굴 경로이기 때문입니다.

```bash
brew install yt-dlp
```

없으면 클로드가 먼저 알려드리고, 설치를 기다리지 않고 다른 경로로 진행합니다.

```bash
brew install yt-dlp
```
