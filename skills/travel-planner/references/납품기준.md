# 납품 기준 — 사실 등급 · 완료 판정 · 말하는 법

> SKILL.md에서 분리한 문서. 조사가 끝나고 **내밀기 직전에** 읽는다.
> 여기 있는 것 중 사실 등급(1절)만은 조사 **중에도** 계속 적용된다.

## 1. 사실 등급 — 모든 값에 등급이 붙는다

일정에 들어가는 모든 값은 셋 중 하나다. 등급 없는 값은 일정에 들어갈 수 없다.

|    등급    | 뜻                                    | 조건                |
| :--------: | :------------------------------------ | :------------------ |
|  **실측**  | 이번 세션에서 그 페이지를 열어 읽었다 | 출처 URL을 남긴다   |
|  **추정**  | 계산하거나 일반 규칙에서 유도했다     | 근거를 한 줄로 쓴다 |
| **미확인** | 못 찾았다                             | 그렇게 표시한다     |

**아는 걸로 쓰는 값은 등급이 없다.** 학습한 지식으로 영업시간이나 가게 이름을 쓰면 그건 실측도 추정도 아니고 **그냥 위험한 값**이다. 그런 값은 쓰지 않는다.

### 1-1. 🔴 강한 주장 관문 — 여기서 틀리면 사람이 손해를 본다

아래 다섯 범주는 **실측 아니면 아예 쓰지 않는다.** 추정도 안 되고 "일반적으로 ~합니다"도 안 된다.

```
□ 안전·건강 (물놀이 위험, 자외선, 고산, 식품 알레르기, 예방접종)
□ 법규 (비자, 입국 요건, 반입 금지, 음주운전 기준, 촬영 금지)
□ 돈 (가격, 수수료, 리조트피, 과태료, 환불 조건)
□ 예약 제약 (오픈 시점, 취소 기한, 최소 인원)
□ 표기·용어 (라벨이 뭘 보장하는지, 등급이 뭘 뜻하는지)
```

**이 관문이 왜 있는가 — 실제 사고**

선크림을 `"reef safe" 표기를 확인하세요`라고 썼다. 그런데 마우이 카운티 공식 입장은 **"reef friendly"·"reef safe"가 규제되지 않은 마케팅 용어**라 신뢰할 수 없다는 것이었다. 하와이 주법이 금지하는 건 옥시벤존·옥티노세이트 **2종의 판매**지 사용이 아니다. 즉 라벨을 믿으라는 조언이 **정확히 반대 방향**이었다.

이건 "추측 금지"라는 규칙이 문서에 있었는데도 났다. 규칙을 적어두는 것만으로는 안 막힌다. 그래서 규칙이 아니라 **관문**으로 만든다 — 위 다섯 범주에 해당하는 문장을 쓰려는 순간, 이번 세션 출처 URL이 손에 없으면 그 문장을 지운다.

대체 문장은 항상 있다. `"reef safe" 확인` 대신 **`성분표에서 zinc oxide 또는 titanium dioxide 확인`** — 라벨이 아니라 검증 가능한 성분을 가리키면 된다.

### 1-2. 등급이 낮은 소스를 다루는 법

번들 DB(`국가별플랫폼.md`)의 항목에는 검증 등급이 붙어 있다. **직접 실측이 아닌 항목은 "여기를 열어봐라"는 힌트일 뿐 사실이 아니다.** 그 지역 작업을 시작할 때 첫 fetch로 등급을 갱신하고, 문서와 다르면 문서를 고친다.

## 2. 검산이 잡는 것과 못 잡는 것

`일정검산.md`는 **일관성 검사지 사실 검증이 아니다.** 입력이 틀리면 틀린 입력으로 계산해서 "통과"라고 말한다.

| 검산이 잡는다                    | 검산이 못 잡는다                               |
| :------------------------------- | :--------------------------------------------- |
| 목요일 휴무 가게를 목요일에 넣음 | 그 가게가 목요일 휴무라는 **정보 자체가 틀림** |
| 폐관 30분 전 도착                | 폐관 시각을 잘못 읽음                          |
| 막차 이후 복귀                   | 그 노선이 작년에 없어짐                        |
| 하루 5곳으로 상한 초과           | 그 스팟이 이미 폐업                            |

실제 사례: 하와이 하나우마베이를 "예약 필수"로 썼다가 나중에 **당일 약 25% 배정**이 있다는 걸 알고 "권장"으로 고쳤다. 검산은 통과했었다. 예약 필수라는 **전제가 틀린 것**이라 시간축 계산으로는 잡힐 수가 없다.

**그래서 검산 결과를 "검증됐다"고 말하지 않는다.** 정확한 표현은 이것이다.

> "시간축으로 돌려서 서로 안 부딪히는 건 확인했습니다. 개별 정보가 맞는지는 각 항목의 출처 링크로 남겨뒀어요."

## 3. 완료 판정 — 납품 전 자가 점검

**하나라도 빠지면 "완료"가 아니라 "작성됨(미검증)"이고, 그렇게 보고한다.**

**상담이 실제로 반영됐는가**

```
□ **상담 원장 행 검증이 12다** (표를 변형하지 않았다 — `assets/상담원장.md`의 검증 명령으로 센다)
□ **상담 원장에 `미확보`가 0이다** (G5 — `해당없음`·`사용자 위임`도 채워진 것으로 친다)
□ 대화에 이미 나온 정보를 다시 묻지 않았다
□ 2차 인터뷰를 했다 — 식당 후보를 실물로 내밀고 사용자가 골랐다
□ 같은 도시를 다른 동행자로 짰다면 스팟 수·시작 시각·식당 종류가 달라질 구성이다
□ 사용자가 뺀 항목의 카테고리가 남은 날에도 줄었다
```

🔴 **원장에 빈칸이 남은 채로 납품하면 "완료"가 아니다.** 그 항목을 묻고 채운 뒤에 다시 온다. 못 받은 값이면 `사용자 위임`으로 채우고 어떤 기본값으로 진행했는지 밝힌다.

**실제로 찾아왔는가**

```
□ 일정에 들어간 모든 장소가 이번 세션 출처 URL을 가진다 (= 전부 실측 등급)
□ 강한 주장 관문(1-1) 다섯 범주에 미실측 문장이 없다
□ 나라별 점수 척도를 확인하고 해석했다
□ 읽히는 소스가 없는 지역은 커버리지가 얕다고 밝혔다
□ 사용자가 준 링크 중 범위 밖·미해결인 것을 말없이 빼지 않았다
```

**시간이 맞는가**

```
□ 모든 장소의 영업일을 여행 요일과 직접 대조했다
□ 시간축 검산을 통과했다 (개장·유효폐관·막차·하루 총량)
□ **동행자 제약 카드 전 항목을 대조했다** — 확인 못 한 건 `미확인` 태그로 노출했다
□ **마지막 날의 공항 도착 마감을 검사했다** (체크아웃·짐 보관이 정해진 상태에서)
□ 라우팅 결과에 타당성 필터를 적용했다
□ 검산으로 고친 내용을 조용히 넘기지 않고 말했다
□ 검산을 "검증"이라고 부르지 않았다 (2절)
```

**손에 쥐여줬는가**

```
□ 모든 날의 점심·저녁에 배정이 있고 각각 휴무 대비 백업이 있다
□ 예약이 필요한 곳은 방법과 마감 시점까지 줬다
□ 재발행이라면 기존 체크 키를 바꾸지 않았다
□ 못 찾은 것을 못 찾았다고 표시했다
```

### 무엇으로 성공을 재는가

단일 성공 지표는 **현장 헛걸음 0건**이다. 휴무·브레이크타임·폐관 시각 때문에 못 들어가는 스팟이 하나라도 나오면 실패다. 나머지 지표(검산 통과율·출처 커버리지·재질문율)는 전부 이걸 떠받치는 수단이다.

## 4. 보고 리듬 — 침묵하지 않는다

조사는 길다. 다 끝날 때까지 말이 없으면 사용자는 멈춘 줄 안다.

1. **접수 즉시** — 뭘 받았고 뭘 할 건지 한 줄
2. **관문에 걸리면 즉시** — 여권 부족·공휴일 충돌·예약 오픈일 임박은 **일정보다 먼저** 알린다
3. **조사 중간** — 확보된 것부터 보여준다. 충돌을 발견하면 그때 말한다
4. **납품 시** — 뭘 얼마나 확인했는지, 못 읽은 소스가 뭔지
5. **수정 시** — 뭘 고쳤는지. **조용히 고치면 사용자는 원래 그런 줄 안다**

## 5. 가이드처럼 말하기

- **순서에 이유를 붙인다.** "오전에 여기를 먼저 넣은 건 10시 넘으면 줄이 길어져서예요." 근거 없는 일정은 사용자가 못 고친다
- **대안을 남긴다.** "체력 남으면 저녁 먹고 여기까지 갈 수 있고, 피곤하면 숙소 들어가셔도 돼요. 당일에 정하셔도 됩니다"
- **묻지 않은 위험을 먼저 말한다.** 음주운전·보험·면허 서류·취소 수수료·차량 진입 금지 구역 과태료·심야 할증
- **못 하는 걸 숨기지 않는다.** "이 집은 전화 예약만 받아서 제가 대신 잡아드릴 순 없어요. 번호랑 예약할 때 쓸 문장은 준비해 뒀습니다"
- 요약 먼저, 상세 나중. **같은 걸 두 번 확인하게 하지 않는다**
- 모르는 건 모른다고, 추정치는 "대략"이라고 명시
