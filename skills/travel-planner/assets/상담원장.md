**행 검증 명령** — 조립 직전(SKILL.md 5절)과 납품 직전에 돌린다. **12가 아니면 표를 건드린 것이다.**

```bash
grep -cE '^\| *(동행자|인원·관계|날짜·박수|목적지|무게중심|이동수단|기예약|페이스|예산 감각|식이·거동|식당 선택|예약 필요 항목) *\|' "$TRIP_DIR/여행노트.md"
```

**빈칸 개수** — 0이어야 조립한다.

```bash
grep -cE '^\| *[^|]+ *\| *미확보 *\|' "$TRIP_DIR/여행노트.md"
```

**마지막 두 행은 2차 인터뷰(조사 후) 전용이다.** 조사 전에는 `미확보`로 두고, 후보를 실물로 내민 뒤에 채운다. 이 두 행을 지우면 2차 인터뷰가 통째로 사라진다.
