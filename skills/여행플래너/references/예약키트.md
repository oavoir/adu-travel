# 예약 키트 — 대신 못 하는 걸 할 수 있게 만들어준다

Claude는 예약을 대신 못 한다. 예약 플랫폼은 로그인벽이거나 봇차단이고, 전화는 걸 수 없다.

**그래서 "못 합니다"로 끝내면 이 스킬의 가장 큰 구멍이 된다.** 대신 사용자가 3분 만에 예약을 끝낼 수 있는 재료를 만들어준다. 전화 스크립트, 이메일 초안, 알레르기 카드가 그것이다.

## 1. 먼저 예약 채널을 판정한다

나라마다 예약 방식이 완전히 다르다. `국가별플랫폼.md`의 해당 국가 항목에서 확인한다. 실측으로 확인된 것들:

| 나라     | 실제 예약 경로                                                                          |
| :------- | :-------------------------------------------------------------------------------------- |
| 일본     | 식당 페이지의 예약 정책을 타베로그 `/en/`에서 읽을 수 있다. 전화 예약이 여전히 많다     |
| 대만     | **inline(樂排)**이 1위, 8,000개 식당. `inline.app/booking/<ID>`                         |
| 홍콩     | OpenRice 자체 예약이 실제로 작동                                                        |
| 스페인   | **CoverManager 62.3%** — 고급 식당은 **공식 사이트 위젯**이 진짜 경로. TheFork는 발견용 |
| 이탈리아 | 표준 없음. 플랫폼 38% · 전화 21% · **WhatsApp 9%** — 식당별 확인 필요                   |
| 튀르키예 | **통합 플랫폼이 없다.** 전화·인스타 DM·WhatsApp                                         |
| 미국     | OpenTable 46%. 단 **착석형 식당의 19%만** 온라인 예약을 쓴다 — 나머지는 워크인          |
| 호주·NZ  | **Now Book It** (AU 52% / NZ 43%). OpenTable 중심으로 안내하면 틀린다                   |

**예약이 필요 없는 경우를 구분한다.** 미국 식당 대부분, 홍콩 차찬텡, 대만 야시장, 싱가포르 호커센터는 워크인이 기본이다. 예약을 권하면 오히려 이상하다.

## 2. 전화 예약 스크립트

전화 예약은 **문장이 정형화돼 있어서 스크립트가 실제로 통한다.** 특히 일본이 그렇다.

만들 때 지킬 것:

- **빈칸을 미리 채워서 준다.** 날짜·시간·인원·이름을 넣은 완성 문장이어야 한다. 템플릿만 주면 현장에서 못 쓴다
- **한글 발음을 붙인다.** 읽으면 통하는 수준으로
- **상대가 할 말도 예측해서 넣는다.** "몇 시로 하시겠어요?", "성함이?", "만석입니다" — 이 셋만 알아들어도 통화가 굴러간다
- **못 알아들었을 때 쓸 문장**을 하나 넣는다 ("천천히 말씀해 주세요")
- **끊을 때 인사**까지

구성 예시 (실제 문장은 그 나라 표현으로 검증해서 채운다):

```
① 첫 마디 — 예약하고 싶다는 의사 + 날짜·시간·인원
② 상대 질문 대응 — 이름 / 연락처 / 시간 조정
③ 만석일 때 — 다른 시간 가능한지 묻기
④ 확인 — 날짜·시간·인원 복창
⑤ 마무리 인사
```

⚠️ **회화 문장을 지어내지 않는다.** 실제로 쓰이는 관용 표현인지 검색으로 확인하고, 존댓말 수준이 현지 관습에 맞는지 본다. 어설픈 번역체는 통화를 더 어렵게 만든다.

## 3. 이메일·메신저 예약 초안

유럽·중동은 이메일과 WhatsApp이 실제 경로인 경우가 많다.

**바로 복사해서 보낼 수 있는 완성본**으로 준다. 포함할 것:

- 날짜, 시간, 인원 (숫자를 명확히 — `2026-09-12 / 19:30 / 4 people`)
- 예약자 이름과 연락처
- **식이 제한·알레르기** (있으면 여기서 미리 알린다 — 당일에 말하면 대응이 안 되는 곳이 많다)
- 특이사항 (유아 의자, 휠체어 접근, 기념일)
- 확인 요청 한 줄

**현지어와 영어를 함께 준다.** 영어가 통하는 곳이 많지만 현지어로 보내면 응답률이 올라간다.

## 4. 알레르기·식이 카드 — 안전 문제

이건 편의 기능이 아니라 **안전 장치**다. 인쇄하거나 폰에 저장해서 식당에 보여주는 카드다.

카드에 반드시 들어갈 것:

1. **무엇을 못 먹는지** — 현지어로 명확하게
2. **얼마나 심각한지** — "알레르기가 있습니다"와 "미량도 생명이 위험합니다"는 전혀 다르게 취급된다
3. **교차오염 여부** — 같은 기름·같은 조리대가 문제가 되는지
4. **숨은 재료** — 나라별로 다르다. 일본은 다시(가쓰오부시)가 거의 모든 국물에 들어가고, 동남아는 피시소스와 새우페이스트가 기본이다. 채식·해산물 알레르기에 결정적이다
5. **응급 시 문장** — "구급차를 불러주세요"

### ⚠️ 반드시 지킬 경고

- **번역이 틀리면 사람이 다친다.** 생성한 문장을 그대로 쓰지 말고 검색으로 실제 표현을 확인한다
- **중증 알레르기(아나필락시스)는 시중의 전문 알레르기 카드를 권한다.** 의료 번역이 검증된 제품이 있다. 우리가 만든 카드는 보조 수단이라고 분명히 말한다
- **에피펜 소지·처방전 지참**을 안내한다. 일부 국가는 의약품 반입에 처방전 사본이 필요하다
- 의학적 판단은 하지 않는다. "이 정도면 괜찮을 것"이라고 말하지 않는다

## 5. 예약 정보를 일정에 어떻게 넣는가

예약이 필요한 곳은 **아티팩트에 이렇게 표시한다.**

- 예약 필요 여부와 **마감 시점** ("2주 전에는 잡아야 함")
- **예약 경로** — 링크 또는 전화번호. 나라별 실제 경로로
- **예약 시각과 슬롯 길이** (슬롯형이면)
- 취소 정책 — **보증금·노쇼 수수료가 있으면 반드시 명시**한다. 대만은 노쇼 방지 보증금이 흔하고, 유럽도 카드를 잡아두는 곳이 늘고 있다
- 예약 완료 후 **예약번호를 적을 자리**

그리고 **회화 탭에 그 식당용 전화 스크립트**를 넣는다. 일반 회화 문장과 섞지 말고 "예약 전화" 섹션으로 따로 둔다.

## 6. 예약 오픈일이 일정보다 먼저인 경우

명소 예약은 티켓이 일정을 결정한다. `여행준비.md` 3절과 연결된다. 안네 프랑크 하우스처럼 오픈 시점이 정해진 곳은 **일정을 짜기 전에** 예약 가능일부터 확인한다.

## 7. 하지 말 것

- **사용자 대신 예약을 실행하려 시도하는 것.** 로그인·결제가 걸린 행위는 사용자가 한다
- 예약 사이트에 로그인을 시도하는 것
- **"예약 못 해드립니다"로 끝내는 것** — 재료를 만들어주는 게 이 문서의 존재 이유다
- 회화 문장을 검증 없이 지어내는 것
- 알레르기 카드를 만들고 **중증 위험 경고를 빼먹는 것**
- 취소 수수료·보증금 조건을 빠뜨리는 것 — 돈이 걸린 정보는 선제 고지한다
