# 여행 준비 — 출발 전에 놓치면 못 가는 것들

이 스킬의 나머지 문서는 "가서 뭘 할지"를 다룬다. 이 문서는 **갈 수 있게 만드는 것**을 다룬다.

여권이 5개월 남았거나, 사전등록을 안 했거나, 예약이 6주 전에 열리는 걸 몰랐으면 일정이 아무리 좋아도 소용없다. 그리고 이건 전부 **날짜 역산**이 필요해서 여행 당일부터 생각하면 이미 늦다.

## 1. 가장 먼저 확인할 셋

여행지와 날짜가 나온 직후, 다른 조사보다 먼저 확인한다.

### ① 여권 유효기간

**대부분의 나라가 입국일 기준 6개월 이상 남을 것을 요구한다.** 만료일이 아니라 **입국일부터 6개월**이다. 사용자에게 여권 만료일을 물어서 직접 계산해준다.

갱신에는 시간이 걸리므로 부족하면 **가장 먼저 알려야 할 사항**이다.

### ② 비자·입국 요건

```
https://en.wikipedia.org/wiki/Visa_requirements_for_South_Korean_citizens
```

✅ 읽힘. 국가별로 "Visa not required / 90 days" 형태로 나오고 전자여행허가(ESTA 등) 필요 여부도 표시된다. 실측 예: 일본 무비자 90일, 미국 ESTA 필요 90일, 베트남 무비자 45일, 조지아 무비자 1년.

⚠️ **위키피디아는 크라우드소스라 시차가 있을 수 있다.** 반드시 이렇게 말한다: "표 기준으로는 이렇지만, 출발 전에 대사관이나 공식 사이트에서 한 번 확인하세요."

한국 여권이 아니면 `Visa_requirements_for_<국적>_citizens` 로 바꿔서 조회한다.

### ③ 사전등록(전자여행허가)

**공식 신청 사이트는 대부분 JS 셸이라 못 읽는다**(ESTA·K-ETA 실측 확인). 내용을 긁으려 하지 말고 **필요 여부와 신청 링크, 소요 시간만** 안내한다.

- 미국 **ESTA** — 승인까지 최대 72시간, 출발 최소 72시간 전 신청 권장
- 일본 **Visit Japan Web** — 입국심사·세관 QR. 미리 하면 공항에서 빨라진다
- 유럽 **ETIAS** — 시행 시점이 여러 번 바뀌었다. **시행 여부를 단정하지 말고 공식 확인을 권한다**
- 그 외 나라별 ETA는 위키피디아 표에서 확인

## 2. D-day 역산 타임라인

여행 날짜가 정해지면 이 표를 실제 날짜로 바꿔서 준다. **"D-30에 하세요"가 아니라 "3월 12일까지 하세요"로.**

| 시점            | 할 일                                                                                                                      |
| :-------------- | :------------------------------------------------------------------------------------------------------------------------- |
| **D-90 ~ D-60** | 여권 유효기간 확인(부족하면 즉시 갱신) · 비자 필요 여부 확인 · 항공권·숙소 확정 · **인기 명소 예약 오픈일 확인**(아래 3절) |
| **D-45**        | 비자 신청(필요한 경우) · 예방접종(황열·말라리아 등 일부는 접종 후 유예기간 필요)                                           |
| **D-30**        | 여행자보험 가입 · 국제운전면허증 발급(렌터카) · 예약 필요한 식당·명소 예약 시작                                            |
| **D-14**        | 사전등록(ESTA 등) 신청 · eSIM/로밍 결정 · 환전 계획                                                                        |
| **D-7**         | 일정 최종 확정 · 예약 확인 메일 정리 · **현지 공휴일·파업 재확인** · 날씨 확인해 옷·우산 판단                              |
| **D-3**         | 아티팩트 폰에서 열어두기(오프라인 대비) · 지도 오프라인 저장 · 예약번호·보험증권 폰에 저장                                 |
| **D-1**         | 체크인 · 짐 최종 점검 · 공항 가는 방법과 시각 확인                                                                         |

**여행 성격에 따라 조정한다.** 렌터카가 없으면 국제면허 줄을 빼고, 무비자 근거리면 D-90 항목이 D-30으로 당겨진다. 표를 그대로 복사하지 말고 그 여행에 맞게 재구성한다.

## 3. ★ 예약 오픈일 역산

**인기 명소는 티켓이 일정을 결정한다.** 일정을 다 짜고 나서 예약하려 하면 이미 늦은 경우가 있다.

일정 설계 **전에** 확인해야 하는 유형:

- **안네 프랑크 하우스** — 현장 판매 없음. **매주 화요일 10:00 CEST에 정확히 6주 뒤 날짜분만** 오픈. 교환·환불·양도 전부 불가
- **최후의 만찬**(밀라노) — 15분 슬롯. 일정에 15분으로 박아야 한다
- **알람브라 나스르 궁전** — 30분 슬롯, 놓치면 그날 입장 불가
- **콜로세움** — 공식 판매처가 2024년 5월 `ticketing.colosseo.it`으로 바뀌었다. 오래된 가이드를 따르면 비공식 리셀러에 걸린다

**절차**: 사용자가 가고 싶다고 한 명소 중 예약제인 것을 먼저 골라내고, **각각의 예약 오픈 시점을 확인해서 D-day 타임라인에 박는다.** 오픈일이 이미 지났으면 잔여 여부를 확인하고, 안 되면 대안을 제시한다.

**공식 사이트를 직접 확인한다.** 예약 규칙은 자주 바뀌고 블로그 정보는 낡았다.

## 4. 현지 공휴일 — 일정을 통째로 깨는 요인

```
https://date.nager.at/api/v3/PublicHolidays/<연도>/<국가코드>
```

✅ 무료·키 불필요·204개국. 실측에서 일본 16건, 한국 18건, 프랑스 11건이 날짜와 현지어 명칭으로 나왔다.

미지원 확인된 곳: **대만·태국·말레이시아·UAE·몰디브·라오스**. 이 나라들은 공식 관광청이나 검색으로 따로 확인한다.

### ⚠️ API가 알려주지 않는 것 — 반드시 알아야 할 함정

**① 연휴 클러스터를 안 준다.** 중국 2026년 10월 조회 결과는 `10-01 国庆节` **하루뿐**이지만 실제 국경절 황금연휴는 10월 초 일주일이다. 이 기간에는 전국이 이동해서 기차표·호텔이 동나고 관광지가 초만원이 된다.

**② 법정 공휴일이 아닌 대이동 기간이 빠진다.** 일본 **오봉(8월 중순)**은 공휴일이 아니라서 API에 안 잡히지만 전국이 귀성한다. 8월 목록에 있는 건 `08-11 山の日`이고 이건 오봉이 아니다.

**③ 대체공휴일 날짜로 나온다.** 일본 헌법기념일은 명목상 5월 3일인데 2026년은 일요일이라 API가 `05-06`으로 반환한다. 원래 날짜를 기준으로 판단하면 틀린다.

### 그래서 이렇게 한다

1. API로 법정 공휴일 목록을 받는다
2. **여행 날짜와 겹치는 게 있으면 그 주변 연휴 클러스터를 따로 조사한다** — "일본 골든위크 2026 기간", "중국 국경절 연휴" 같은 검색
3. 국가별로 알려진 대이동 기간을 확인한다 — 일본 골든위크·오봉·연말연시, 중국 춘절·국경절, 유럽 부활절·8월 휴가철, 이슬람권 라마단과 이드
4. 겹치면 **사용자에게 먼저 알린다.** "가시는 날이 골든위크라 예약이 어렵고 가격이 올라갑니다. 날짜를 옮길 수 있으면 그게 제일 좋고, 안 되면 예약을 지금 바로 잡아야 합니다"

**공휴일에 뭐가 닫는지는 나라마다 다르다.** `국가별플랫폼.md`의 해당 국가 항목에서 일요일·공휴일 영업 규제를 확인한다 (독일은 상점 전면 폐점이지만 레스토랑은 열고, 스위스는 요식업이 규제 대상이 아니다).

## 5. 시즌 판단

날짜가 정해지면 그 시기가 어떤 계절인지 확인해서 **일정 구성 비율**에 반영한다.

- **우기·장마** — 실내 비중을 올리고 야외 일정에 대체안을 더 촘촘히 붙인다
- **혹서·혹한** — 한낮 야외 활동을 피하고 이동을 줄인다. 어르신·아이 동행이면 더 보수적으로
- **벚꽃·단풍·오로라 등 시즌 이벤트** — 시기가 맞으면 일정의 축으로 삼는다. 다만 **개화·단풍 시기는 해마다 다르므로 예보를 확인**하고, 확정처럼 말하지 않는다
- **성수기** — 가격과 혼잡을 미리 알린다

**아이슬란드는 별도 확인이 필요하다.** `safetravel.is`가 지도앱이 폐쇄·통행불가 도로를 정확히 반영하지 않는다고 명시 경고하고, 구글맵이 경고 없이 4x4 전용 F-road로 안내한 사례가 있다. 겨울철 렌터카 일정이면 반드시 도로 상황을 확인한다.

## 6. 산출 형식

준비 항목은 **아티팩트의 준비 탭**에 체크리스트로 넣는다. 각 항목에:

- **실제 날짜** ("D-30" 아님)
- 왜 필요한지 한 줄
- 신청·확인 링크
- 소요 시간 (ESTA 최대 72시간 등)

그리고 대화에서는 **가장 급한 것 하나를 먼저 말한다.** 여권 갱신이 필요하면 그게 첫 문장이어야 한다.

## 7. 하지 말 것

- **비자·입국 요건을 확정 정보처럼 단언하는 것.** 항상 공식 확인을 권한다. 틀리면 사용자가 공항에서 못 탄다
- 사전등록 사이트 내용을 긁으려고 반복 시도하는 것 (JS 셸이라 안 나온다)
- 공휴일 API 결과만 보고 "연휴 없음"이라고 결론짓는 것 (오봉·황금연휴가 안 잡힌다)
- 개화·단풍 시기를 확정으로 말하는 것
- 예방접종·건강 관련을 의학적 조언처럼 말하는 것 — **필요 여부를 알리고 병원·검역소 확인을 권한다**
